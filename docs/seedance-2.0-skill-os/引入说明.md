## 跟 doubaox 工作流怎么接

- 写/改**出视频 prompt** 时先查:`references/vocab/zh.md`(中文词表)、
  `skills/seedance-examples-zh/`(中文示例)、`references/i2v-guide.md`(图生视频)、
  `references/multishot-grammar.md`(一条 prompt 多镜语法)、
  `references/dense-storyboard-mode.md`(密集分镜模式,对应我们"喂分镜线稿当图1")。
- **段与段衔接**(我们的 32×10s 拼接):`references/continuation-handoff.md` +
  `skills/seedance-continuation/`——先看上一段实际末帧、记录"观察到的结束状态"再写下一段,
  与工具里的 🎬抽末帧 功能正好配套。
- **出片崩了先查**:`references/failure-atlas.md`(失败图谱)+ `references/retake-protocol.md`
  (重抽协议:每次只改一个变量)。
- **@素材参考角色分工**:`references/reference-transfer-contract.md`(每张参考图声明
  "迁移什么/不迁移什么",和我们 @图N 指认是同一件事的进阶版)。
- 平台差异(豆包/即梦/Ark/API):`references/platform-surface-matrix.md`。
