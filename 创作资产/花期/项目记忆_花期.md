## 2. 关键设定锁（改任何 prompt 前先读）

- **画风锁**：电影级国漫动画CG、现代都市清新治愈系；干净线条 + 赛璐璐叠轻水彩；**不要欧美厚涂/低幼卡通/机甲**。
- **男主**：27 岁左右、约 1米8、清隽帅气（剑眉/桃花眼/清晰下颌线）、白衬衫 + 胸前复古胶片相机（全片信物）。
- **女主**：二十六七岁、约 1米68、**温柔知性·成熟自信的御姐**（杏眼眼尾上扬/微卷大波浪/浅梨涡）。⚠️ 御姐＝气质仪态，**绝不性感化/不暴露**；负面词已从"少女成熟化"翻转为"幼态少女化"（成熟现在是想要的）。初见态＝鹅黄连衣裙抱白花束。
- **预告片开关**：11 段预告片（可快切）/ 21 段一镜到底（不要快切）。安静段千万别写"预告片"，会被带成乱切。
- **只出场男主的段：1/2/8/9** —— 这些段不传女主卡，否则模型硬塞人。

## 3. 出片操作要点（Seedance 2.0 全能参考）

1. 入口：豆包/即梦 Seedance 2.0「全能参考」；**电影级选 P2.0 Pro**。
2. 多图必须 `@图N` 指认职责（不是文字写"参考图1"就行）；上传顺序照每段"上传素材"行。
3. 角色卡正面清晰、**角色细节匹配度拉 80–100%**；不能传写实真人脸（合规拦截）。
4. 半自动投喂用 `工具/🎬 豆包投喂-全能参考-0.3.1.user.js`（v0.3.1 双模式：直接载入本目录《全能参考版》成品文件 → 逐字用 + 按"上传素材"行自动排配图；也兼容四字段源现场套 @素材）。分镜/场景图文件名开头数字对段号（`06_xx.png`→第6段）。
5. doubaox 工具内：分镜编辑器有「📋 全能参考视频Prompt」按钮（本次新增），按本镜引用的角色/场景动态排 @图N。
6. 写 prompt / 出片崩了 / 段间衔接，先查 `docs/seedance-2.0-skill-os/`（Seedance 2.0 方法论知识库，中文入口 `docs/README.zh.md`；对接清单见其《引入说明.md》）。
