# 《噬渊》道具提示词库

> 道具定型卡 = 纯白背景上的物体多角度参考图,无场景、无人物、无手持。
> 目的是让同一道具在所有镜头里造型/材质/颜色一致。
> 用法:粘进 道具库 / 画布生成器。

---

# 1. 噬渊珠(吞噬黑球)· 全剧核心道具 ⭐

> 这是整部剧的核心物。黑暗天神把全部修为/权柄/记忆/黑暗法则本源压成的黑球。
> 第 1 集它是"沉睡态"(蒙灰、死寂);集末被黎尘的血唤醒,深处亮起一点幽光。
> 设计要做两个状态,后期还会有"完全觉醒态"(暂不画)。

## 1a · 沉睡态(第 1 集大部分时间)

```
2D 写实国漫,东方玄幻,8K 超高清,纯白干净背景,16:9 横版,道具设定参考图。
只放道具本体,多角度展示,无场景、无人物、无手持、无背景装饰。

道具:噬渊珠 —— 一颗沉睡了多年的神秘黑色球体,约拳头大小。
通体纯黑,表面是哑光的、像被烧焦过的质地,毫无光泽,死寂。
表面蒙着一层薄薄的灰尘,有岁月沉积感,毫不起眼,像一块普通的黑石。
球体表面隐约有极淡的、几乎看不见的暗纹(法则纹路,沉睡时不发光)。

布局:画面里展示同一颗黑球的三个角度 —— 正面、3/4 侧、稍俯视,间距均匀。
光照:纯白背景下的柔和均匀打光,体现哑光死寂的黑色质感和表面灰尘。
一致性:三个角度是同一颗球,造型/质地/灰尘分布 100% 一致。

严格禁止:不要发光、不要幽光、不要能量特效、不要粒子(这是沉睡态,死寂)、
不要场景、不要人物、不要手、不要文字标注、不要色彩参考板、
不要低清晰度、不要模糊、不要塑料感、不要 Q 版。
```

## 1b · 初醒态(第 1 集集末,血唤醒后)

```
2D 写实国漫,东方玄幻,8K 超高清,纯黑暗色背景,16:9 横版,道具设定参考图(觉醒瞬间)。
只放道具本体,无场景、无人物、无手持。

道具:噬渊珠 —— 刚被唤醒的神秘黑色球体,约拳头大小。
通体纯黑哑光,表面有一道滴落的暗红血迹。
球体深处,亮起一点幽冷的暗金 / 紫黑色微光,像在亿万里黑暗中睁开的一只眼睛。
表面原本沉睡的暗纹此刻泛起极淡的幽光,法则纹路若隐若现。

布局:聚焦展示这颗球,正面 + 一个稍近的细节特写(突出深处那点睁开的幽光)。
光照:幽暗环境,光主要来自球体内部那点微光,神秘、不祥、克制(不要太亮太夸张)。
氛围:沉睡之物初醒的一瞬,诡异、压抑、令人不安。

严格禁止:不要大面积发光 / 爆闪(只是一点深处微光)、不要夸张能量爆发特效、
不要场景、不要人物、不要手、不要文字标注、不要低清晰度、不要模糊、不要塑料感、不要 Q 版。
```

一致性:各视图是同一把剑,造型/磨损/布条缠法 100% 一致。

## 不用单独建卡的道具(镜头里顺带描述即可)

这些只出现一两个镜头、不需要严格一致,直接在 shot 的画面描述里写清楚就行:

- **包子(段3)**:一个还冒着热气的普通白面馒头 / 包子。
- **竹筐 / 杂物筐(段2)**:一个粗编竹筐,装着杂物(柴、布、杂货)。
- **扫帚(段5)**:一把普通的竹枝扫帚 / 高粱扫帚。

## 后期会用到的道具(暂不画,等剧情推进)

- **觉醒态黎尘身上的锁链 / 符牌 / 古玉 / 暗纹腰饰** —— 这些算"服装配饰",建议放进觉醒态黎尘的角色卡里一起出,不单独建道具。
- **昭离的执法神器**(若后期需要) —— 等他正式动手那集再设计。
- **法阵 / 阵盘 / 灵石 等修仙通用道具** —— 按剧情需要时再补。

---

## 生成顺序建议

到这里第 1 集的素材就齐了:**角色(黎尘凡人态 + 昭离 + 小满 + 玄朴)+ 场景(9 张)+ 道具(4 张)**。

建议生成顺序:
1. **先角色**(尤其黎尘凡人态 —— 后面镜头全靠它做参考)
2. **再场景**(9 张定场图)
3. **再道具**(这 4 张)
4. **然后进 AI 拆分镜的每个 shot** —— 用 🔗 连线把对应的角色 / 场景 / 道具图连到镜头生成器节点,保证一致性
5. 出图 → 出视频 → 末帧衔接 → 拼接

核心物 **噬渊珠** 优先生成,因为它是全剧贯穿的关键,值得多试几版挑最好的。
