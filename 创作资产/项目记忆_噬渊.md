## 2. 创意项目《噬渊》(原名《黑暗天神》,剧透所以改名)

### 核心
一个修仙宗门最底层的杂役少年**黎尘**,体内封印着远古**黑暗天神(真名:渊)**。
核心冲突不是复仇爽文,是"**我是谁**"—— 黎尘 vs 渊共用一具身体。

### 关键人物 + 命名(别记错)
| 角色 | 身份 | 要点 |
|---|---|---|
| **黎尘** | 16岁杂役少年(主角) | 体内是黑暗天神。隐忍、清贫、护小满、苦练剑 |
| **渊** | 黎尘体内的黑暗天神真名 | **第8集才揭真名**,前面只是"黑球/噬渊珠里的东西" |
| **昭离** | 天界执法神(反派) | **悲剧反派**:女儿昭微死于黑暗法则失控,用千年复仇填丧女之痛。不是无脑恶人 |
| **小满** | 8岁厨房杂役女童 | 黎尘的人性锚点。黎尘偷塞包子给她 |
| **玄朴真人** | 苍梧宗化神长老(师父) | 沉静有城府,认得黑暗法则气息 |
| **商珏** | 内门天才弟子(反派配角) | 傲慢刻薄,欺负黎尘。段2踢筐、段4高台、段9撕剑谱 |
| **噬渊珠** | 核心道具 | 黑暗天神压缩成的黑球。沉睡态(蒙灰死寂)/初醒态(深处一点幽光) |

### 叙事结构铁律(钩子管理)
- **第1集零神** —— 只立黎尘这个底层少年,集末血滴黑球、深处幽光睁开作钩子
- **异瞳推到第4集**才出现
- **真相(他=黑暗天神容器)推到第7-8集**
- 用户原《黑暗天神》那个"10秒讲完整个故事"的开篇,挪到**第8集当记忆闪回**
- **第1集黎尘全程凡人态**:双眼正常深黑、无异瞳、无裂纹、粗布弟子服。绝不能剧透

### 黎尘的视觉进化(3套定型卡)
| 阶段 | 集数 | 特征 |
|---|---|---|
| 凡人态 | 1-3 | 双眼正常深黑,青灰粗布弟子服,干净 |
| 半觉醒 | 4-7 | 左眼偶尔黑金,裂纹初现 |
| 觉醒态 | 8+ | 黑金异瞳常驻,脸/脖裂纹,暗紫破损神袍+锁链符牌(用户已自己生成这张) |

### 视觉配色策略(撑电影级 + 主题)
- **黎尘/黑暗法则 = 黑 + 暗紫 + 冷**
- **昭离/天界 = 白 + 金 + 光**
- 两边对立,一眼分阵营。天界之巅(辉煌)↔黑暗天牢(毁灭)用同构图做对比

## 3. 豆包上传卡0%问题(已查明 → 转手动)

**现象**:工具浏览器传参考图卡0%,正常浏览器能传。
**根因**:`mssdk.bytedance.com`(字节设备安全/反爬SDK)检测出工具用的是Playwright自动化浏览器
(navigator.webdriver、TLS指纹等),**直接掐断连接**(ERR_CONNECTION_CLOSED)→拿不到上传token→卡0%。
**不是网络/代理问题**(正常浏览器同网络能传),**不是账号封号**(那会返403)。是反爬专门针对自动化。

**决策:转纯手动**。在正常浏览器里手动生成,工具只当辅助。
- 否决了两个逆向API:`doubao-api-free`(Java,只聊天+文生图,无参考图无视频)、
  `doubao2API`(Python,同样只聊天+文生图,无参考图无视频,且都用同一个被掐的账号)
- **豆包seedance视频没有靠谱免费逆向方案**(都止步文生图)
- 官方付费路:**火山引擎(Volcano Engine)ARK** 的 seedance(视频)+ seedream(图,带参考图),
  稳定不封号但按量付费。用户暂未决定是否走这条

## 4. 豆包出片铁律(本次会话一路测试验证出来的,最值钱)

> 核心认知:**复杂度是豆包的敌人**。每条视频压到最简单就稳,一复杂(多人/切镜/对话堆一起)就翻车。

1. **一条10s = 一个镜头 = 一个地点 = (有台词时)一个说话人**
   - 换地点 → 换一条(之前段3厨房+膳堂塞一条,豆包跳场景赶工)
   - 对话戏 → 拆成单人说话镜头(之前膳堂三人同框,管事被画错、口型乱)

2. **★"预告片"开关(最大发现)**:prompt里写"**10秒电影预告片**" = 让豆包做**快切多镜蒙太奇**;
   不写 = 豆包做**一镜到底连续镜头**(切不了机位,会吞镜头)。
   - **要切机位的多镜头段(膳堂/广场/神殿)→ 加"预告片"** → 4格全演到 ✓已验证
   - **单一连续动作段(山顶练剑)→ 不加** → 一镜到底,顺
   - 已用对照测试坐实:同板同文字,带"预告片"的明显爱切镜、全对

3. **故事板大图要带全角色脸**(包括管事这种配角)。没脸的会被画错/和别人串脸
   (段4第一次管事没脸→被画成白袍年轻人和商珏混;第二次板顶加了执事长老脸→对了)

4. **多图指认**:给豆包传多图时文字里点名"图1=黎尘、图2=场景、图3=商珏",锁脸不串 ✓已验证有效

5. **凡人态锁**:第1集黎尘全程双眼正常深黑、无异瞳、无裂纹。负面词必带

6. **台词**:豆包能自带语音,但要"**台词时镜头固定不推拉 + 只让说话的人张嘴**",否则口型乱、认错人。
   保险起见台词可在剪映加字幕+TTS配音(剪映文本朗读/魔音工坊)兜底。
   注:剪映"对口型"功能要真人脸验证,**AI动漫角色过不了**,别指望它

7. **段间衔接**:段内靠运镜/快切;段间靠**剪映硬切 + 时间光线推移**(拂晓→清晨→午后→夜→次日),
   不用末帧morph(那是给同一连续动作跨两条10s用的)

### 用户的实际工作流(已确认)
**先用GPT镜像站画出故事板大图**(4格 + 顶部角色脸条 + 台词气泡那种)→ **再把大图喂豆包生视频**(prompt里带"预告片"+主体描述+负面词)。
所以要给用户的是**"画故事板大图的prompt"**,不是直接给豆包的纯文字。
