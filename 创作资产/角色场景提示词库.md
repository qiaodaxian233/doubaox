# 《噬渊》提示词库 · 角色 + 场景

> 全部对齐世界圣经。角色用"6 面 + 3 视图"干净定型卡格式;场景用电影级环境参考图格式。
> 配色策略:黎尘/黑暗 = 黑+暗紫+冷;昭离/天界 = 白+金+光。两边对立,一眼分阵营。
>
> 用法:角色卡粘进 角色库 / 画布生成器;场景图粘进 场景库 / 画布生成器。

# 一、反派 · 昭离(天界执法神 / 失去女儿的父亲)

> 设计要点:他不是无脑反派,是个用千年复仇填补丧女之痛的神。
> 视觉上要"神性威严"+"深藏的悲伤",冷而不狰狞。和黎尘的黑暗形成光/暗对立。

```
2D 写实国漫,东方玄幻。生成角色 昭离(天界执法神) 的角色定型卡,8K 超高清,纯白干净背景,16:9 横版布局,画面工整、无重叠、无遮挡、严格只放人物本体,人物之间留有清晰间距。

布局要求(严格执行,不要自由发挥):
- 左侧上下两排,共 6 格面部多角度肖像:
  · 上排三格:正面威严、左侧 3/4 侧脸、右侧 3/4 侧脸
  · 下排三格:正脸冷峻、侧脸隐含哀伤、半侧脸俯视(各种神情)
- 右侧三格:全身三视图,标准 A-pose 站姿
  · 正面立绘、左侧面立绘、背面立绘
- 全身三格之间间距均匀,人物身高对齐

角色外观描述:
成年男性神祇,身形高大挺拔,神性威严,气场沉静而压迫。
面容俊美而冷硬,轮廓分明,眉骨高,眼神锐利但深处藏着难以察觉的悲伤与疲惫(一个失去女儿、追凶千年的父亲)。
银白色长发,束成利落的高髻,几缕垂落。
肤色冷白如玉,皮肤干净完整。
双眼为浅金色 / 银灰色,沉静、威严。
穿天界执法神的华贵神袍:以纯白、银、金为主色调,层叠式神袍结构,金色秩序纹样刺绣,银色金属护肩与护腕,长袍庄重垂坠,质感高级。
气质:神性、秩序、威严、孤高,深藏丧女之痛。

一致性要求(关键):
- 9 格内同一人五官、脸型、发型、发色、肤色、瞳色 100% 一致
- 服装(版型/配色/纹样/护肩/腰带) 100% 一致
- 人体结构精准、无畸变、无穿模、无多余手指

严格禁止(负面词):
- ❌ 不要黑色/暗紫色(那是黑暗法则的配色,昭离是对立的光/金阵营)
- ❌ 不要狰狞、不要邪恶反派脸,他是悲伤克制的神,不是恶魔
- ❌ 不要武器、法器、持有物
- ❌ 不要能量特效、粒子、光纹、符文飘浮
- ❌ 不要色彩参考板、材质参考块、场景背景、文字标注
- ❌ 不要低清晰度、模糊、人物崩坏、Q版、塑料感皮肤
```

# 四、场景 · 苍梧宗(黎尘的世界 / 第 1 集主场景)

> 用法:这是黎尘日常生活的宗门。白天、缥缈、有人间烟火气。第 1 集大量用。
> 场景图不需要"6 面 + 3 视图",要的是一张干净的电影级环境定场图,方便后续所有
> 这个场景的镜头保持一致。

```
2D 写实国漫,东方玄幻,国漫电影级 CG,8K 超高清,16:9 横版宽画幅电影定场镜头。

场景:苍梧宗 —— 悬浮在云海之上的修仙宗门。
连绵的悬空仙山,山峰被翻涌的白色云海环绕,几道飞瀑从山间垂落没入云中。
山体上层层叠叠的东方古典宫观建筑群:飞檐斗拱、白墙黛瓦、朱红廊柱、石阶蜿蜒,
殿宇之间有石桥与回廊相连。古松点缀山间。
晨光熹微,金色的阳光穿过薄雾洒在飞檐上,有清晨的人间烟火气和仙气并存。

光照:清晨柔和的金色侧光 + 薄雾散射,通透、明亮、有体积光。
氛围:缥缈、清幽、有生活气息的修仙圣地,日常感而非压迫感。
镜头:超广角电影定场镜头,纵深感强,天空占画面上半部。

严格禁止:不要人物、不要现代建筑、不要西式城堡、不要黑暗/紫黑色调(这是光明的日常场景)、
不要文字标注、不要低清晰度、不要模糊、不要塑料感、不要 Q 版、不要廉价特效。
```
