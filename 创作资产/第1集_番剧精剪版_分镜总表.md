# 《噬渊》第 1 集 · 番剧精剪版 · 分镜总表

> 目标规格：**国产 3D 写实仙侠番**（《凡人修仙传》的写实克制 + 《斗罗大陆》的分镜密度与精度）。
> 风格不变——沿用你现有两条的 2D 写实 CG 质感，只把**规格**顶上去。
> 配套文件：`第1集_10段故事板大图_新格式.md`（每场的完整画大图 prompt 在那）、`项目记忆_噬渊.md`。
> 账号/额度：5 个豆包账号 = **35 额度**，按"多拍 + 重抽 + 精挑"用，不再为省额度妥协。

---

## 0. 总基调（先定死，全片统一）

- **风格**：2D 写实国漫 CG，写实人物 + 仙侠世界，不变。番剧感来自**镜头多、节奏准、声音厚、调色统一**，不是改画风。
- **调色**：全片一条**冷峻电影底**（青灰冷基调）。按场景情绪微调——厨房/梦境偏暖、神殿压暗、广场高亮但**压一档高光防曝**。剪映里调好一条 LUT/滤镜，复制到全部片段。
- **光影**：单一动机光源 + HDR + 体积光/丁达尔；暗部要有细节，别死黑。
- **节奏**：文戏镜头略长（2–4s 留情绪），冲突/高潮镜头短促密集（1–2s）。整集镜头数比现在**翻 3–4 倍**（约 50–70 个独立小镜头）。
- **声音**：分层（环境底噪 + 逐动作音效 + 情绪配乐 + 留白）+ 声音搭桥。详见 §3。
- **台词**：走 TTS（剪映/魔音工坊）+ 字幕，**不用豆包自带语音**（口型不稳，达不到番剧线）。
- **凡人态锁**：黎尘全程双眼正常深黑、无异瞳、无裂纹、青灰粗布弟子服。唯一异常 = 末尾黑球一点暗金幽光（克制不爆闪）。

## 1. 拍法变了（这是和"片段集"拉开差距的关键）

| 旧（求稳） | 新（番剧精剪） |
|---|---|
| 一段 = 一条 10s，4 镜塞一条里 | **一场 = 七八个独立短镜，每镜单独生成** |
| 靠"预告片"开关在一条里塞多镜 | **基本弃用"预告片"**——每镜只演一个干净动作（3–5s，剪掉头尾留 1–2s），在剪映里切 |
| 段间硬切/转场 | **运动接刀（match cut）**：用动作/视线接力，刀口吃在动作里看不见 |
| 怕崩脸，少切 | 35 额度 + 重抽，**多拍多挑**，崩了就重生成那一条 |

**三条铁规（每镜都照做）：**
1. **每镜只一个动作**（推门 / 挥斧 / 抬头 / 一滴血落下）。动作越单一，豆包越稳、越干净。
2. **标死"进画方向 → 出画动作 → 视线朝向"**——这是 match cut 能成的前提，剪的时候按方向接。
3. **每镜都 🔗 连凡人态黎尘卡 + 场景图锁脸**；多人/新脸（小满/玄朴/商珏）继续用多图指认（图1=黎 图2=对方 图3=场景）。

## 3. 声音设计层（番剧感最被低估、却几乎零额度）

每条片段在剪映里**分四层**叠：
1. **环境底噪**（贯穿整场）：山风/鸟/殿内回响/广场人声/夜虫。一场一条，铺满。
2. **逐动作音效**（点）：脚步、衣料、斧劈、纸撕、茶盏、灰落、门响。对着画面动作贴。
3. **情绪配乐**（线）：整集一条连续的配乐床（这条也负责把硬切"听顺"）；按情绪起落调音量。
4. **留白**（最高级）：高潮/情绪点前**突然抽掉所有声音半拍**——段9 碎纸慢镜、段10 血滴前，各留一次白，再砸回来。
- **声音搭桥**：下一场的声音垫在上一场镜头尾巴下 0.3–0.5s 先进（段8→9 的嗤笑声、段X→10 的殿内死寂）。画面没切声音先到，散镜头立刻被缝成流。

## 4. 接刀/转场总表（每个场间怎么接）

| 场间 | 时间 | 接法 | 理由 |
|---|---|---|---|
| 1→2 | 拂晓→清晨 | **match cut**（视线+下行方向） | 动作承接 |
| 2→3 | 清晨→午后 | 硬切 + 情绪反差 | 冷→暖对撞 |
| 3→4 | 午后→午后 | **match cut**（黎走出→走入） | 同时段 |
| 4→5 | 午后→夜 | **短黑场 0.3s + 5.0 月夜空镜** | 入夜大跳，黑场吃掉亮度差 |
| 5→6 | 夜→深夜 | **match cut**（起身→推门进屋） | 承接 |
| 6→7 | 深夜→梦境 | **淡入**（柔焦梦境） | 段7本是柔化段 |
| 7→8 | 入黑→次日明亮 | **硬切**（留黑半拍）招牌黑→亮 | 对比冲击，全片最强一刀 |
| 8→9 | 次日→次日午后 | **声音搭桥 + match**（玄朴忧虑视线→弟子受欺） | 室内静→外景亮人群落差大，靠声桥+忧虑视线缝 |
| 9→X | 午后→黄昏 | match（被差去打扫→上山） | 自然带去神殿 |
| X→10 | 黄昏 | **match cut**（走向殿门→进殿） | 动作连贯 |

> 原则：**室内→外景、空→满人、暗→亮 这类大落差，一律给缓冲**（短黑场/叠化/空镜/声桥），别裸切；同时段、有动作或视线接力的，用 match cut 把刀藏进动作里。

## 5. 贯穿线（把散场景缝成"一集"的暗线）

观众读"连贯"，靠的是人和物反复出现，不是转场。全集埋三条，剪时确保它们**视觉上前后呼应**：
- **剑谱**：段1 练剑的执念 → 段6 视若珍宝地夜读（特写 6.3）→ 段9 被商珏当众撕碎（特写 9.2）。一条因果线，两段一拎就成戏。
- **小满 / 包子**：段3 偷塞包子（黎自己饿着）——立人性锚点，后续集回收。
- **练剑记号**：段1 练剑 → 段6 墙上划满半面墙的炭笔记号（6.4）。无声地说"他练了很久"。
- **凡人态黎尘本人**：每场都 🔗 同一张卡锁脸，反复出现 = 最强的"同一个人连续的一天"。

---

## 6. 后期清单（贴图感→片子感）

- **统一 LUT/调色**：调好一条复制到全部，压住豆包飘色。
- **电影颗粒 + 暗角**：极轻一层，去"干净的塑料 CG 感"。
- **虚焦前景**：部分镜头前挂个虚焦的柱子/烟/草，做景深层次（番剧常用）。
- **慢镜**：仅段9 碎纸（9.4）、段10 血滴（10.5）用，别滥用。
- **字幕 + TTS 配音**：剪映/魔音工坊；台词镜头嘴动的人对得上即可，不强求精准对口型。

---

## 7. 额度分配（35 额度怎么排）

- 全集约 **55–65 个独立小镜 + 10 个空镜**。空镜/单人镜成功率高，1 额度多半一遍过。
- **难镜留重抽余量**：多人同框（段4/9）、新童脸（段3 小满）、高潮（段10 血滴+睁眼）——每个预留 2–3 次重抽挑最好。
- 建议轮次：先把**空镜 + 单人镜**全跑一遍（稳、快、攒底）；再集中火力刷**多人镜和高潮镜**，反复挑。
- 5 个号并行，一两天能跑完一轮 + 重抽，完全够这种"多拍精挑"的拍法。

---

## 一句话

番剧感是**剪**出来的，不是单条生成出来的：镜头多、每镜单动作、按视线/方向 match cut、声音分层 + 留白、调色统一。35 额度全砸在"多拍 + 重抽 + 精挑"上，就能把"片段集"做成"一集番"。
