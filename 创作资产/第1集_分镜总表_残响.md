# 《残响》第 1 集 · 分镜总表（精简 · 22 段对齐版）

> 配套:`第1集_全字段源_残响.md`(权威源)、`第1集_22段_画大图prompt_残响.md`(每段完整画大图prompt在那)、`世界圣经_残响.md`、`第1集剧本_残响.md`。
> **本片拍法 = 1 段 = 1 条 10s 视频**(已确认不灌水)。段内是"一镜到底"还是"快切多镜",由**预告片开关**决定。22 段 × 10s ≈ **3 分 40 秒**。
> 额度:22 个视频额度(+难段重抽);5 个豆包号 = 25/日,一天一轮 + 重抽够。
> (若要《噬渊》那种"番剧精剪"密集版——每段拆 7-8 小镜、镜头翻 3-4 倍、55-90 小镜、额度翻几倍——另说,本份是精简版。)

---

## 0. 总基调（先定死,全片统一）

- **风格**:2D 写实近未来科幻 CG,双世界。人间冷写实(高级灰 / 玻璃白 / 过度干净,**绝非赛博朋克霓虹**);数据界深空黑底 + 青(cyan)/品红数据光。番剧感来自**节奏准、声音厚、调色统一、贯穿线缝**,不是堆画风。
- **调色**:全片一条冷峻电影底。人间冷灰;数据界压黑提青光;**红色只用于警示**(段3销毁 / 段8上传 / 段14倒计时);**唯一暖色**留给段19追思会女儿那一抹。剪映里调好两条 LUT(人间冷灰 / 数据界青),复制到对应段。
- **光影**:单一动机光源 + HDR;数据界唯一光源是数据光;暗部留细节,别死黑;数据态可加极轻辉光但**克制不爆闪**。
- **节奏**:文戏镜头略长(留情绪 2–4s 感);冲突 / 高潮段(5/8/16/20/21)短促密集。
- **声音**:四层(环境底噪 / 逐动作音效 / 情绪配乐 / 留白)+ 声音搭桥。详见 §3。
- **台词**:走 TTS(剪映 / 魔音工坊)+ 字幕,**不用豆包自带语音**。**数据态沈渡用处理过的冷"数据音"**(加一点电子混响 / 失真),跟人间态区分开。
- **双世界态锁**:人间沈渡=46岁清瘦带血丝、深灰青灰近未来科研服;江临=34岁憔悴执拗、深色高领科研服;沈知=19岁素白;数据态沈渡=青色明灭半透明人形数据轮廓、无清晰五官、克制不爆闪。**招牌转场段10→11 黑→数据光**。

## 1. 拍法（本片的精剪逻辑）

| 旧"片段集" | 本片(精简精剪) |
|---|---|
| 一条里硬塞多镜、靠运气 | **1 段 = 1 条 10s**,段内一镜/多镜由**预告片开关**定 |
| 段间硬切 | **运动接刀(match cut)**:动作/视线/状态接力,刀口吃进动作里 |
| 大落差裸切(人间↔数据界) | **给缓冲**:黑场 / 数据光转场 / 声桥(见 §4) |
| 怕崩脸少切 | 难段(多人/新脸/数据态明灭)**留重抽**,崩了重生成那一条 |

**预告片开关(段内一镜 vs 多镜):**
- **加(快切多镜蒙太奇)**:段5 争执 / 段8 上传 / 段16 险逃 / 段18 我死了 / 段20 凶手与女儿 / 段21 千眼睁开 —— 多人 / 正反打 / montage / 宏大段。
- **不加(一镜到底,更稳不崩脸)**:其余 16 段 —— 单人 / 独处 / 钩子定格段。

**三条铁规(每段照做):** ① 段内动作尽量单一干净;② 标死"进画方向→出画动作→视线/状态朝向"(match cut 前提);③ 每段 🔗 连对应角色卡 + 场景图锁脸,新脸(江临/沈知/数据态沈渡)多图指认。

## 3. 声音设计层（番剧感最被低估、几乎零额度）

每条片段在剪映里**分四层**叠:
1. **环境底噪**(贯穿整场):人间=实验室设备低鸣/应急嗡声、城市夜车流远响;数据界=数据流电子细响、深空黑的空旷回响。一世界一条,铺满。
2. **逐动作音效**(点):门被撞开、硬盘摔碎、心跳监护(段8拉成长音)、探头接驳、数据脉冲"咚"、格式化白光轰鸣、摄像头接通音。对着画面动作贴。
3. **情绪配乐**(线):整集一条连续配乐床(也负责把硬切/转场"听顺");人间冷弦、数据界空灵合成器,段5/8/16/20/21 推上去。
4. **留白**(最高级):高潮/情绪点前**抽掉所有声音半拍**——**段8 上传前**、**段13"他杀了我"前**、**段22 切黑前**各留一次白,再砸回来。
- **声音搭桥**:下一段的声音垫在上一段尾巴下 0.3–0.5s 先进。关键三处:**段9→10** 服务器低频心跳垫进入黑;**段16→17** 数据界青光声→城市底噪先入;**段17→18** 新闻播报声先入(画面没切声音先到)。

## 5. 贯穿线（把散段缝成"一集"的暗线）

观众读"连贯",靠人和物反复出现 + 因果回收,不是转场。全集埋五条,剪时确保前后呼应:
- **忘川协议 / 94%**:段1「完整度100%」的成功 → 段3 要亲手销毁 → 段8 上传卡 **94%**(残缺之源)→ 段12 数据态记忆缺失(那 6% 丢的人味)回收。一条"残缺"因果线。
- **女儿 / 未接来电**:段2 未接来电 + 亡妻忌日 → 段19/20 追思会孤身 → 段22「我会回来的,知知」回收。沈渡的人性锚点。
- **凶手江临**:段4–9 杀人 + 掩盖 → 段18 被捧为继承人 → 段20 靠近女儿 → 段22「让你亲身体会一遍」立誓。全剧引擎线。
- **烛龙之眼**:段9 备用服务器指示灯 → 段17 第一只摄像头之眼 → 段21 全城千眼睁开。一条"眼"由暗到明的线。
- **数据态沈渡本人**:每段 🔗 同一张数据态卡锁形,反复出现 = 最强的"同一个'鬼'连续"。

## 6. 后期清单（贴图感 → 片子感）

- **两条统一 LUT**:人间冷灰 / 数据界青,各自复制到对应段,压住豆包飘色。
- **电影颗粒 + 暗角**:极轻一层,去"塑料 CG 感"。
- **数据界辉光**:轻,**克制不爆闪**;红色只在警示处(段3/8/14)。
- **慢镜**:仅段8 「94%定格」、段10 「入黑」、段16 「格式化白光」三处,别滥用。
- **字幕 + TTS**:剪映 / 魔音工坊;**数据态沈渡用冷数据音**(电子混响/轻失真),与人间态区分。
- **招牌转场**:段10→11 的黑→数据光,单独精修(全黑半拍的时长、青色脉冲的起势)。

---

## 7. 额度分配（22 视频额度怎么排）

- 全片 **22 段 = 22 个视频额度**(+难段重抽)。空镜/单人/数据态独处段成功率高,多半一遍过。
- **难段留重抽余量**:多人同框(段5/8/20)、新脸(段4江临 / 段19沈知)、数据态剧烈明灭(段11/15/16)、宏大千眼(段21)——每个预留 **2–3 次**重抽挑最好。
- 建议轮次:先把**单人 + 数据态独处段**全跑一遍(稳、快、攒底);再集中火力刷**多人 / 高潮 / 宏大段**,反复挑。
- 5 个号 = 25 额度/日,**一天一轮 + 重抽**完全够这种"多拍精挑"。

---

## 一句话

精剪感是**剪**出来的:预告片开关分一镜/多镜、按 match cut 接刀、声音四层 + 留白、两条 LUT 调色统一、五条贯穿线缝成一集。22 条视频全砸在"多拍 + 重抽 + 精挑"上,就能把"片段集"做成"一集番"。
